# MBTI 진로 나침반

고등학교 창의적 체험활동 시간에 쓰는 MBTI 성격유형 검사와 진로 안내 웹페이지입니다.
32문항(지표당 8문항)을 풀면 유형별 공부 방법, 계열·학과, 직업 정보를 담은 결과지를
A4 한 장짜리 PDF로 저장하거나 인쇄할 수 있습니다.

**바로 가기 →** https://아이디.github.io/mbti/

## 구성

| 항목 | 내용 |
|---|---|
| 문항 | E/I, S/N, T/F, J/P 각 8문항, 총 32문항 |
| 동점 처리 | 4:4로 갈리면 해당 지표에만 결정 문항이 한 개 더 나옵니다 |
| 결과 | 지표별 비율, 강점·보완점, 공부 방법 4가지, 계열·학과, 직업 |
| 저장 | 결과지를 A4 한 장 PDF로 저장 (16개 유형 모두 1쪽) |
| QR | 인쇄물에서 커리어넷·고용24로 바로 연결 |
| 소요 시간 | 약 7분 |

## 사용 방법

교실 PC·태블릿·스마트폰 어디서나 주소를 열면 바로 실행됩니다.
별도의 설치나 로그인, 서버가 필요 없고 학생의 응답은 어디에도 저장되지 않습니다.
모든 계산은 학생의 브라우저 안에서만 이루어집니다.

수업 흐름 예시

1. 학생들이 주소(또는 QR)로 접속해 32문항을 풉니다.
2. 결과 화면에서 **결과 PDF로 저장**을 눌러 A4 한 장을 내려받습니다.
3. 인쇄한 결과지 아래 손글씨 칸에 관심 직업 두 가지를 적습니다.
4. 결과지의 QR로 커리어넷 진로심리검사·직업백과에 접속해 직업을 더 알아봅니다.

## 파일

- `index.html` — 페이지 전체. 외부 라이브러리 없이 이 파일 하나로 동작합니다.
  (QR 코드 생성기, PDF 생성기까지 모두 포함되어 있습니다.)

## 수정하기

`index.html`을 텍스트 편집기로 열어 아래 부분을 찾아 고치면 됩니다.

- 검사 문항 — `const AXES = [` 로 시작하는 부분
- 유형별 내용 — `const TYPES = {` 로 시작하는 부분 (별명, 강점, 공부 방법, 학과, 직업)
- 공식 진로정보 링크 — `const OFFICIAL = [` 로 시작하는 부분

## 출처와 안내

- 직업·학과 명칭 — 교육부 [커리어넷 직업백과](https://www.career.go.kr/cnet/front/base/job/jobList.do)·[학과정보](https://www.career.go.kr/cnet/front/base/major/FunivMajorList.do), 고용노동부 [워크넷 한국직업사전](https://www.work.go.kr/consltJobCarpa/srch/jobDic/jobDicIntro.do)
- MBTI 활용 원칙 — [Myers &amp; Briggs Foundation, Ethical Use of the MBTI](https://www.myersbriggs.org/unique-features-of-myers-briggs/ethical-use-of-the-mbti/)

MBTI는 능력이나 우열을 가리는 검사가 아니며, 직업을 결정해 주는 도구도 아닙니다.
결과에 나오는 직업은 정답이 아니라 그 성향이 편안하게 발휘될 수 있는 환경의 예시입니다.
진로 지도에는 커리어넷·고용24의 흥미·적성검사 결과와 함께 활용해 주세요.
정확한 성격유형 진단이 필요하면 전문 기관의 정식 검사를 권합니다.

이 페이지는 교육 목적으로 만든 비공식 자료이며, MBTI 상표권자와 관련이 없습니다.
